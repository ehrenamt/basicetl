# basicetl

> Un outil de base pour les processus ETL simples. Il est principalement destiné à être utilisé sur votre ordinateur local.

_English README available at [README.md](README.md)_

# Description

Ce util simplifie les processus ETL en généralisant la vérification des erreurs et la logique d'extraction.

Il prend en charge

- L'extraction à partir de fichiers ```csv```, ```JSON``` et ```XML``` locaux.
- L'extraction à partir de fichiers ```csv```, ```JSON``` et ```XML``` distants via une URL.
